# Hang Timer — голосовой секундомер для виса на перекладине

Одна страница `index.html`. Ни сборки, ни зависимостей, ни интернета.

Голос отсчитывает: `three, two, one, GO`, дальше секунды по-английски — с 1-й по 20-ю каждую
секунду, после 20-й каждые 5 (`twenty five`, `thirty`, `thirty five`, …). По STOP произносит
итог: `forty three seconds`.

## Как открыть локально

Двойной клик по `index.html` — откроется в браузере по умолчанию.

Всё работает, **кроме Screen Wake Lock**: при открытии через `file://` этот API недоступен,
и страница покажет предупреждение. Для локального прогона либо поставьте в настройках телефона
/ компьютера автоблокировку экрана на «Никогда», либо поднимите локальный http-сервер:

```bash
python -m http.server 8000
```

и откройте `http://localhost:8000/` (localhost считается защищённым контекстом, Wake Lock работает).

## Как выложить на GitHub Pages

1. Создайте на GitHub пустой публичный репозиторий, например `hang-timer`.
2. Положите в него `index.html` (файл обязательно должен лежать в корне репозитория).

```bash
git init
git add index.html README.md
git commit -m "hang timer"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/hang-timer.git
git push -u origin main
```

3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`, **Save**.
4. Через минуту страница будет доступна по адресу
   `https://ВАШ_ЛОГИН.github.io/hang-timer/`.

Это адрес по https, поэтому там работает Wake Lock — экран не гаснет во время подхода.

## Как добавить на домашний экран телефона

Открывайте именно https-адрес с GitHub Pages, не `file://`.

- **iPhone (Safari):** кнопка «Поделиться» (квадрат со стрелкой вверх) → **На экран «Домой»** →
  **Добавить**.
- **Android (Chrome):** меню «⋮» в правом верхнем углу → **Добавить на главный экран** (или
  **Установить приложение**) → **Добавить**.

Иконка появится среди приложений и будет открывать таймер одним касанием.

## Если не слышно голоса

По порядку:

1. **Нажмите TEST VOICE** в блоке «Настройки» — он произносит `one two three`. Это проверка звука
   до подхода, а не во время него.
2. **Громкость медиа, а не звонка.** На телефоне это две разные громкости. Нажмите кнопку
   громкости *во время* звучания TEST VOICE — тогда регулируется именно медиа-канал.
3. **iOS: выключите «Бесшумный режим»** — переключатель на левом торце iPhone должен быть
   отжат от себя (оранжевой полоски не видно). В бесшумном режиме синтез речи молчит.
4. **Проверьте, что звук идёт в наушники:** переподключите Bluetooth-гарнитуру, убедитесь, что
   телефон вывел звук на неё, а не на динамик.
5. **Первое нажатие — обязательно START или TEST VOICE.** Браузеры (особенно Safari) включают
   синтез речи только после касания экрана; звук не может стартовать «сам».
6. Внизу страницы подписан выбранный голос. Если там «Английский голос не найден» — озвучка
   поедет системным голосом другого языка и числа могут звучать странно. Доустановите английский
   голос: iOS — *Настройки → Универсальный доступ → Устный контент → Голоса*;
   Android — *Настройки → Система → Языки и ввод → Синтез речи*.
7. Если слова наезжают друг на друга или отстают — снизьте **скорость речи** до 1.0–1.1 или
   переключите режим озвучки на «каждые 5 секунд».

## Настройки

Свёрнуты в блоке «Настройки», сохраняются в `localStorage`:

- **подготовительный отсчёт** — 3 / 5 / 10 секунд (по умолчанию 3). Вслух произносятся только
  последние три секунды и `GO`; до этого на экране идут цифры молча;
- **режим озвучки** — «каждую секунду до 20, дальше каждые 5» (по умолчанию) / «каждую секунду
  всегда» / «каждые 5 секунд» (метки 5, 10, 15, …);
- **скорость речи** — 0.8–2.0 (по умолчанию 1.2);
- **опережение речи** — 0–400 мс (по умолчанию 150). Компенсирует задержку между вызовом
  синтеза и реальным началом звука, чтобы слово «ten» звучало *в момент* 10-й секунды.
  Слышно, что голос запаздывает — увеличьте; что торопится — уменьшите.

## Как устроена точность

- Момент `GO` фиксируется как абсолютная метка `performance.now()`; всё время считается от неё,
  а не накоплением тиков — дрейф не копится.
- Озвучка N-й секунды планируется на абсолютное `startTime + N*1000 - опережение`.
- Тик каждые 50 мс сверяет фактическое время с расписанием.
- Перед каждым словом вызывается `speechSynthesis.cancel()` — очередь речи не растёт и не
  сдвигает расписание.
- После возврата из фона пропущенные метки **не проговариваются пачкой**: озвучивается только
  актуальная последняя, и то если она опоздала меньше чем на 1.2 с.

Проверено прогоном на 30+ секунд: к 30-й секунде отставание озвучки от расписания — около 12 мс.
